How to Use These Fonts

1. For Websites (Recommended: WOFF2)

Add to your HTML head:

<link rel="preload" href="/fonts/roboto.woff2" as="font" type="font/woff2" crossorigin>

<style>
@font-face {
  font-family: 'Roboto';
  src: url('/fonts/roboto.woff2') format('woff2'),
       url('/fonts/roboto.woff') format('woff');
  font-display: swap;
}

body { font-family: 'Roboto', sans-serif; }
</style>

2. For Desktop Applications

Download the TTF format and install on your system:

  • Windows: Right-click TTF file → Install
  • Mac: Double-click TTF file → Click Install Font
  • Linux: Place TTF in ~/.local/share/fonts/ → Run fc-cache

3. For Design Tools

Works with: Adobe Creative Suite, Figma, Sketch, Affinity, and other design applications

  • Download TTF or OTF format
  • Install on your system
  • Fonts appear in your design tool's font menu

File Formats Explained

  • WOFF2: Best for web - smallest file size, excellent browser support
  • WOFF: Web format - good compatibility with older browsers
  • TTF: Desktop/Print - standard format for system fonts
  • OTF: Desktop/Print - advanced font format with additional features

Performance Tips

Optimize Font Loading

  • Use WOFF2 format for best compression
  • Use font-display: swap to avoid font loading delays
  • Preload critical fonts with rel="preload"
  • Subset fonts to include only necessary characters
  • Use variable fonts when available to reduce file count

CSS Example with font-display

@font-face {
  font-family: 'Roboto';
  src: url('/fonts/roboto.woff2') format('woff2');
  font-display: swap; /* Shows fallback immediately */
}
